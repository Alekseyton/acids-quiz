Сайт представляет собой интерактивный тренажёр для подготовки к ЕГЭ по химии в разделе «Кислоты». Он предназначен для проверки и закрепления знаний соответствия названий кислот их химическим формулам.

Тренажёр предлагает задания с выбором одного правильного ответа из четырёх вариантов и обеспечивает мгновенную проверку результата. Реализованы два режима работы: неограниченный по количеству заданий и с заранее заданным числом вопросов. По завершении тренировки выводится статистика правильных и ошибочных ответов.

В приложении также предусмотрен справочный раздел с таблицей формул и названий кислот, доступный для изучения перед началом занятий.
